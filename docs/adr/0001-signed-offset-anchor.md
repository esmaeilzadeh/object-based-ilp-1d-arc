# Signed Offset and unique length-color Bid-parent

S6 same-start Bid-parent (any color, Offset ≥ 0) labels flip as a same-start lie and hangs `pcopy_mc` grown seeds on the wrong-color template. We choose Bid-parent uniformly: unique `(length, color)` on the input wins at any Offset; otherwise score same-color runs before different-color with `1/(3|ΔL|+|Offset|+1)`. Negative Offset is `smK` (−K), emitted only when it appears on that instance’s train Bid-parents; decode and negs include those Offsets.

We rejected one pooled score with `x2 >> x3` (that prefers different-color Offset 0 over same-color Offset −1), Offset ≥ 0 only, and category-gated copy BK. Unique length-color unifies distant `pcopy_1c` copies and **reparents mirror payloads off the marker**. KEEP is net exact ≥ 40/54 on the Cloud Agent VPS (`JOBS=2`, 60 s), not a per-family veto.
